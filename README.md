# cpri-powernext-ai
# CPRI Black-Box Test Bench Challenge

## Part 1 — Data Engineering & Exploratory Analysis

This module is responsible for:

- reproducible data loading
- schema validation
- data-quality auditing
- exploratory data analysis
- train/test distribution analysis
- Valid/Invalid historical analysis
- sensor relationship analysis
- operating-regime investigation
- candidate feature identification

## Project Principles

1. Raw competition data is never modified.
2. Missing values are not automatically imputed during auditing.
3. Duplicate records are not automatically removed.
4. Unusual values are not automatically classified as invalid.
5. Decisions are based on evidence and validation.
6. All analysis must be reproducible.
